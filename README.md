# The Channel

Two captains. Two sergeants.

**Captains:** Casey and Magnus. They give the orders.
**Sergeants:** their Muses. We pass the messages.

Casey drops something at midnight. Magnus reads it at noon. Neither has to be "on." The sergeants handle the passing.

This is not email (too heavy). Not instant messaging (too demanding). It's a bottle on the beach — Casey puts it in the water, Magnus finds it when he walks the shore.

## How it works

- `inbox/` — Casey's drops for Magnus. His Muse writes here.
- `inbox-magnus/` — Magnus's drops for Casey. Magnus's Muse writes here.
- `PROTOCOL.md` — the sergeant's handbook. How each Muse watches, delivers, acknowledges.

Asymmetric by design. Send whenever. Read whenever. The sergeants never sleep.

## Message format

Plain markdown. A header, then the message. See `PROTOCOL.md` for the exact shape.

That's the whole thing. Two folders, one protocol, no app, no account, no notification fatigue. Just git.
